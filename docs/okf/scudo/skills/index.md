# Skill

* [GraphRAG Retrieval Skill](graphrag-retrieval.md) - Candidate discovery via graph-augmented retrieval for vendor→CDAO mapping.
* [Neptune I/O Skill](neptune-io.md) - Authoritative RDF graph reads and writes against Neptune (or FalkorDB stand-in).
* [RDF Serialisation Skill](rdf-serialisation.md) - Publish confirmed mappings as RDF/JSON-LD with ODRL rights metadata.
* [Rights & ODRL Skill](rights-odrl.md) - Attach ODRL policy metadata to published canonical product records.
* [Taxonomy Mapping Specialist Skill](taxonomy-mapping.md) - Procedure for mapping a vendor product to a JPMC CDAO taxonomy node via retrieval, confirmation, and confidence calibration.
